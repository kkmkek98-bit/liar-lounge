# 🦊 Liar Lounge — 강아지 탈을 쓴 여우를 찾아라

PeerJS(WebRTC) 기반, 서버 없이 브라우저끼리 연결되는 멀티 채팅 라이어 게임입니다.

▶ **플레이:** https://kkmkek98-bit.github.io/liar-lounge/

## 친구들과 하는 법
1. 위 링크 접속 → 닉네임 입력 → **방 만들기 (Host)**
2. 상단의 5자리 **방 코드**를 친구에게 공유
3. 친구는 같은 링크에서 방 코드 입력 → **입장 (Guest)**
4. 최소 3명(부족하면 AI 봇 추가), 최대 10명

## 특징
- 강아지(시민) vs 여우(라이어), 한 줄 단서 → 자유 토론 → 투표 → 결선 투표 → 여우의 역전 찬스
- 옷장 꾸미기, 이모지 리액션, 의심 화살표, 커스텀 제시어
- 새로고침해도 자동 재접속 (방장 복구 포함)
